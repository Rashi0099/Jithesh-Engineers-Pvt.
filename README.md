# Jithesh Engineers Pvt. Ltd. — Web Portal & Corporate Profile

Official web portal and digital presence for **Jithesh Engineers Pvt. Ltd.**, a premier structural engineering consultancy established in 2008 in Calicut (Kozhikode), Kerala, with extensive operations across India and Saudi Arabia.

---

## About the Consultancy

Founded and led by **Er. K. Jithesh** (MTech Structural Engineering, CEng, MIE, ICI - practicing in the construction industry since 1991), Jithesh Engineers delivers structural analysis, 3D BIM rebar detailing, industrial PEB engineering, long-span spatial trusses, deep foundation engineering, and structural health audits adhering to IS Codes, ACI 318, and international standards.

---

## Features & Architecture

- **Architectural Slate Design System**: Clean, understated engineering aesthetic utilizing slate/charcoal tones, frosted glass accents, and responsive typography.
- **100% Mobile-Optimized**: Fully responsive edge-to-edge layouts tailored for mobile viewports, responsive navigation drawer, and touch-friendly controls.
- **Official 4-Page Corporate Profile PDF**:
  - Direct downloadable vector PDF (`/Jithesh_Engineers_Corporate_Profile.pdf`) compiled with real company credentials, founder details, national awards, disciplines, and client lists.
  - Interactive modal preview and in-browser printable view (`/corporate-profile-print.html`).
- **Interactive Project Portfolio**: Filterable project gallery covering commercial towers, residential complexes, spatial space frame canopies, and industrial structures.
- **Careers Application Portal**: Expandable career openings with inline resume application modal.
- **Smooth Marquee Client Carousel**: Dual-direction infinite scrolling showcase of marquee clients (Landmark Builders, Pentium Constructions, Good Earth, KHRWS, Konkan Railway, etc.).
- **Direct WhatsApp Widget**: Floating quick-inquiry chat integration.

## Tech Stack

- **Framework**: React 18
- **Language**: TypeScript (Strict Mode)
- **Bundler & Dev Server**: Vite 6
- **Styling**: Tailwind CSS 3
- **Icons**: Lucide React
- **Routing & Navigation**: React Router v6 + Smooth Scroll Spy

## Getting Started

### Prerequisites

- Node.js (v18+)
- npm (v9+)

### Installation

```bash
# Clone the repository
git clone git@github.com:Rashi0099/Jithesh-Engineers-Pvt..git

# Navigate to project directory
cd Jithesh-Engineers-Pvt.

# Install dependencies
npm install

# Start local development server
npm run dev
```

The application will be running at `http://localhost:5173/`.

### Production Build

```bash
# Typecheck and compile production bundle
npm run build

# Preview production build locally
npm run preview
```
